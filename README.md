# Biplap Kushmi — Portfolio (Redesign)

This branch implements an initial redesign for the personal portfolio of Biplap Kushmi.

Files added:
- index.html — single-page site scaffold with HERO, ABOUT, SERVICES, SKILLS, EXPERIENCE, PROJECTS, PROCESS, CERTIFICATES, TOOLS, CONTACT.
- css/styles.css — design tokens and styles.
- js/main.js — nav & accessibility.
- js/contact.js — contact form handler (honeypot). Replace Formspree action in index.html with your Formspree form ID.
- js/three-scene.js — Three.js hero module (progressive enhancement).
- assets/img/* — placeholder images (SVGs used as placeholders).
- sitemap.xml, robots.txt
